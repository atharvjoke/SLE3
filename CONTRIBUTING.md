# CONTRIBUTING

Thank you for your interest in the AI Refrigerator Agent project.

This repository was prepared as part of **SLE-3: Architectural Design (Full C4 Model)** for the course **02AML204 – Introduction to Artificial Intelligence**.

## How to Contribute
1. Read the `README.md` to understand the system and its architecture.
2. If you find an error or have a suggestion, describe it clearly.
3. Keep proposed changes consistent with the AI Refrigerator Agent's purpose and the four C4 levels:
   - Context
   - Container
   - Component
   - Code
4. Use clear names and concise explanations for any added modules, classes, or functions.
5. Do not claim that a feature is implemented unless working code has actually been added and tested.

## Suggested Areas for Improvement
- Add clear C4 diagrams for each architecture level.
- Develop and test a working prototype of the sensor-input and state-management flow.
- Define and test decision rules for cooling, reduced cooling, alerts, and no-change actions.
- Add tests for unusual temperature readings, an open door, and missing item-condition data.
- Improve documentation while keeping it easy for students to understand and explain.

## Reporting an Issue
When reporting an issue, include:
- A short, descriptive title.
- What you expected to happen.
- What actually happened, if applicable.
- Steps to reproduce the issue, if applicable.

## Student Project Note
This is an academic architecture-design project. Suggestions should support learning, clarity, safety, and accurate documentation.
